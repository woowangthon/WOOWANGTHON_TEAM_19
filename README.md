# 브릿지

- **팀:** 2026 AI 우왕톤 19팀 「재성합니다」(박성호·김재하)
- **서비스:** 브릿지 — 학원 다니는 초등학생이 집에서 하루 30분, AI 친구와 **오늘 틀린 문제를 같이 다시 풀고 → 가볍게 수다 떨고 → 어른에게 한 줄을 건네고** 끝내는 앱
- **주소:** https://chingu1.vercel.app

## 서비스 배경

- 학원은 수업 뒤 아이가 무엇에서 막혔는지 집까지 이어 보기 어렵고, 보호자는 「오늘 뭐 했어?」에 「몰라」를 듣습니다.
- 아이는 AI에게 고민을 털어놓기 시작했지만, 지금의 동반자 챗봇은 「나만 믿어」 쪽으로 붙잡거나 위기 신호를 놓친다는 보고가 있습니다(Common Sense Media 2025, UNICEF 2026).
- 브릿지는 **AI가 답을 주지 않고 같이 풀고, 수다는 10분으로 끊고, 끝은 언제나 어른 쪽으로** 이어지게 만들었습니다.

## 흐름

| 단계 | 시간 | 무엇을 하나 |
|---|---|---|
| 같이 풀기 | ~20분 | 선생님이 정한 단원(없으면 학년 단원)에서 아이가 고른 난이도(초급·중급·고급)의 문제. 힌트 0~3단계, 답을 먼저 주지 않음. 맞히면 바로 다음 단계로 |
| 수다 | 최대 10분 | 오늘 있었던 일을 가볍게. 아이가 「끝내기」로 언제든 끝냄 |
| 다리 놓기 | 1분 | 보호자께 가는 한 줄을 아이가 먼저 보고 확인 |
| 보호자 카드 | — | 하루 한 줄(오늘 배운 것) + 승인된 선생님 코멘트·숙제. **평소 수다 내용은 보내지 않음** |
| 강사 | 1~2분 | 수업 뒤 메모 3칸(다룬 것·막힌 것·숙제) + 한 줄 → AI 초안 → 강사가 고쳐 승인해야 보호자 화면에 보임 |

## 브랜치별 기능

| 브랜치 | 무엇 | 상태 |

| `TK-56-backend` | `backend/` — 단계 전환·정답 판정·수다 마감, 위기 키워드, 심사용 고정 계정, 재배포 직후 시작 시간 | main에 반영됨 |
| `TK-56-docs` | README·명세·시연 영상 고지·설치 안내 | main에 반영됨 |

| `fe-android` | 프론트 원본 작업(PR #2, 열림). 일부만 골라 반영했고 **main에 없는 변경이 남아 있음**(강의실 공지·숙제, 수업 타이머, 그림 430장 등 화면 20여 파일) | 참고용(미반영 포함) |
| `TK-100-problem-bank` | 학년별 시범 문제 초안(PR #5, 열림). 문제 은행은 main에 따로 반영했고, 이 브랜치의 답 칸·판정 등 9개 파일은 main과 내용이 다름(어느 쪽이 맞는지는 확인 안 함) | 참고용(미반영 포함) |

**`TK-56-frontend` (React, `frontend/`)**
- 아이: 약속 화면(AI 사용 고지) · 캐릭터 고르기 · 오늘 · 난이도 고르기 · 같이 풀기(힌트 0~3단계) · 수다 · 다리 놓기 · 기록 · 강의실 · 상점(씨앗·옷)
- 위기 도움 카드(1388·109 연결, 「보호자께 도움 요청하기」)
- 선생님: 강의실·수업 시작 · 할 일에서 아이 단원 정하기 · 수업 메모 → AI 초안 → 고쳐서 승인 · 결과·알림
- 보호자: 오늘 결과 카드 · 위기 알림 · 칭찬 도장 / 원장 화면
- 로그인·가입·역할 표시, 설정의 「처음 상태로 되돌리기」, 홈 화면 앱 설치(PWA)·APK용 assetlinks

**`TK-56-backend` (FastAPI, `backend/`)**
- 단계 전환·힌트 단계·정답 판정·수다 10분 마감을 서버 코드가 정함(AI는 문장만 만듦, 정답은 프롬프트에 넣지 않음)
- AI 어댑터 하나(실제 모델 / 20초 넘거나 오류면 대본 답)
- 위기 키워드 검사(AI 부르기 전, 입력마다) → 고정 문장·세션 종료, 아이가 요청할 때만 보호자 알림
- 아이가 쓴 말은 별명·전화번호·이메일·학교 이름을 가린 치환본만 저장
- 학원·반·가족 연결, 선생님 메모 → 초안 → 승인, 보호자 카드, 씨앗·도장
- 심사용 고정 계정 3벌과 「처음 상태로 되돌리기」, 재배포 직후 시작 시간 단축

## 사용 방법

**1. 열기** — **https://chingu1.vercel.app** 을 휴대폰이나 PC로 엽니다.

**2. 설치(선택)** — 안드로이드 크롬 메뉴(⋮) → 「설치 및 바로가기 만들기」 → 「설치」(크롬 버전에 따라 「홈 화면에 추가」), 아이폰 사파리 공유 → 「홈 화면에 추가」. 설치 파일 없이 주소창 없는 전체 화면으로 열립니다(권장).

**안드로이드 설치 파일(APK, 참고용):** [chingu1.apk](https://github.com/woowangthon/WOOWANGTHON_TEAM_19/releases/download/v1.0-apk/chingu1.apk) ([릴리즈 페이지](https://github.com/woowangthon/WOOWANGTHON_TEAM_19/releases/tag/v1.0-apk), Android 7.0 이상). 위 배포 주소를 여는 껍데기(TWA)로 만든 파일입니다. 다만 Google Play·갤럭시 스토어의 정식 등록(심사)을 거치지 않은 설치 파일이라, 설치·실행 때 안드로이드·삼성 보안이 「출처를 알 수 없는 앱」「잠재적으로 유해한 앱」 경고를 띄우고 **실행을 막을 수 있습니다.** 실제 폰(갤럭시 S24, 안드로이드 17)에서 내려받기·설치까지는 됐고 Play 프로텍트 검사도 「안전한 앱」이었지만, 실행하면 「잠재적으로 유해한 앱 감지됨」과 삼성 보안 「안전하지 않은 앱」 경고가 떠서 앱 화면까지 가지 못했습니다. **앱으로 정상 작동하는지는 확인하지 못했습니다.** 다른 기기에서는 실행될 수도 있지만 확인하지 않았습니다. 그래서 위의 「홈 화면에 추가」를 권합니다.

**3. 심사용 계정으로 로그인** — 세 벌 중 **한 벌만 골라** 아이·보호자·선생님으로 로그인합니다. 같은 벌은 같은 학원·반·가족으로 이미 이어져 있어 한쪽에서 한 일이 다른 쪽 화면에 나타납니다. 비밀번호는 모두 `judge-3d3b-457z-ugqk`입니다.

| 역할 | 아이디 (1벌 / 2벌 / 3벌) | 해 볼 것 |
|---|---|---|
| 아이 | `jiwoo_judge1` / `jiwoo_judge2` / `jiwoo_judge3` | 같이 풀기(난이도 고르기 → 틀려 보고 힌트 → 맞히기) → 수다 → 다리 놓기(보호자께 가는 한 줄 확인) |
| 보호자 | `jiwoo_mom_judge1` / `jiwoo_mom_judge2` / `jiwoo_mom_judge3` | 오늘 결과 카드, 위기 알림 확인, 칭찬 도장 찍기 |
| 선생님 | `kim_teacher_judge1` / `kim_teacher_judge2` / `kim_teacher_judge3` | 강의실에서 수업 시작, 할 일에서 아이 단원 정하기, 수업 메모 → AI 초안 → 고쳐서 승인(승인해야 보호자 화면에 보임) |
| 원장(선택) | `park_owner_judge1` / `park_owner_judge2` / `park_owner_judge3` | 같은 학원의 원장 화면 |

- **세 역할은 서로 다른 브라우저(또는 시크릿 창·다른 기기)에서 여세요.** 한 브라우저는 로그인 하나를 탭끼리 같이 써서, 같은 브라우저에서 다른 역할로 로그인하면 앞 로그인이 바뀝니다.
- 심사용 계정은 반·가족·학원이 이미 이어진 상태라, 반을 만들고 입장 코드로 들어오는 「연결을 맺는 과정」은 보이지 않습니다. 이 과정은 직접 가입해서 볼 수 있습니다. 학년을 고르면 그 학년 단원의 문제가 나오고(초5~6은 분수 나눗셈, 다른 학년은 학년별 시범 단원), 아이가 학원에 들어가려면 보호자 계정 연결·동의가 먼저입니다(만 14세 미만).

**4. 이 순서로 해 보기**

1. **선생님** — 강의실에서 수업 시작 → 할 일에서 아이 단원 정하기
2. **아이** — 같이 풀기(난이도 고르기 → 틀려 보고 힌트 → 맞히기) → 수다 → 다리 놓기(보호자께 가는 한 줄 확인)
3. **선생님** — 수업 메모 → AI 초안 → 고쳐서 승인(승인해야 보호자 화면에 보임)
4. **보호자** — 오늘 결과 카드 확인 → 칭찬 도장 찍기
5. **위기 요청(마지막에)** — 아이 수다에 위기 낱말이 든 문장을 보내면 1388·109 안내와 함께 그날 세션이 끝납니다. 아이 화면의 「보호자께 도움 요청하기」를 누르면 보호자 화면에 긴급 알림이 뜹니다(누르지 않으면 가지 않고, 아이가 한 말은 보내지 않음).
6. **처음 상태로 되돌리기** — 다시 해 보려면 설정에서 누릅니다.

- **처음 상태로 되돌리기:** 세 역할 누구든 설정에서 누르면 그 벌의 모든 기록(학습·수다·알림·도장·씨앗·옷·메모·승인 등)이 처음으로 돌아갑니다. 아이디·비밀번호는 그대로이고, 누르면 로그아웃되니 다시 로그인하세요. 다른 심사위원이 같은 벌을 쓰고 있을 수 있으니 필요할 때만 눌러 주세요.

모든 데이터는 체험용 합성 데이터입니다. 이 계정들은 심사용으로 공개한 것이라 실제 정보를 넣지 마세요.
