# 친구1 (chingu1)

학원 다니는 초등학생이 집에서 하루 30분, AI 친구와 **오늘 틀린 문제를 같이 다시 풀고 → 가볍게 수다 떨고 → 어른에게 한 줄을 건네고** 끝내는 앱입니다. 2026 AI 우왕톤 19팀 「재성합니다」.

> 초안(11-14). 시연 범위는 초5~6 분수 나눗셈 시드 20문제 한 영역입니다.

## 왜 만드나

- 학원은 수업 뒤 아이가 무엇에서 막혔는지 집까지 이어 보기 어렵고, 보호자는 「오늘 뭐 했어?」에 「몰라」를 듣습니다.
- 아이는 AI에게 고민을 털어놓기 시작했지만, 지금의 동반자 챗봇은 「나만 믿어」 쪽으로 붙잡거나 위기 신호를 놓친다는 보고가 있습니다(Common Sense Media 2025, UNICEF 2026).
- 친구1은 **AI가 답을 주지 않고 같이 풀고, 수다는 10분으로 끊고, 끝은 언제나 어른 쪽으로** 이어지게 만들었습니다.

## 하루 30분 흐름

| 단계 | 시간 | 무엇을 하나 |
|---|---|---|
| 같이 풀기 | ~20분 | 강사가 정한 「오늘 할 것」 한 문제. 힌트 0~3단계, 답을 먼저 주지 않음. 맞히면 바로 다음 단계로 |
| 수다 | 최대 10분 | 오늘 있었던 일을 가볍게. 아이가 「끝내기」로 언제든 끝냄 |
| 다리 놓기 | 1분 | 보호자께 낼 퀴즈 3택 + 어른에게 가는 한 줄을 아이가 직접 확인 |
| 보호자 카드 | — | 하루 한 줄(오늘 배운 것) + 아이가 낸 퀴즈 + 승인된 선생님 코멘트·숙제. **평소 수다 내용은 보내지 않음** |
| 강사 | 1~2분 | 수업 뒤 메모 3칸(다룬 것·막힌 것·숙제) + 한 줄 → AI 초안 → 강사가 고쳐 승인해야 보호자 화면에 보임 |

## 체험해 보기

1. 배포 주소(제출 때 적음)를 휴대폰이나 PC로 엽니다.
2. 로그인 화면 아래 **「체험 계정으로 둘러보기 (시연)」** 를 누릅니다. 학생·보호자·학습지도자·원장 등 체험 계정 목록이 보이고, 누르면 아이디·비밀번호가 채워집니다(비밀번호는 화면에 표시).
3. 방문자마다 따로 체험 세트가 만들어져 다른 사람과 섞이지 않습니다. 「시연 데이터 처음으로」로 언제든 새로 시작합니다.
4. 순서 추천: 아이로 같이 풀기 → 수다 → 다리 놓기 → 학습지도자로 메모·승인 → 보호자 화면.

모든 데이터는 체험용 합성 데이터입니다.

## 어떻게 만들었나

- **프론트** React(웹, 휴대폰 화면 우선) · **백엔드** FastAPI · **DB** Postgres · **배포** Vercel.
- **AI** Claude Haiku 5.5. 공급자는 어댑터 하나 뒤에 숨겨 두었고, 20초 안에 답이 없거나 오류면 미리 쓴 대본 답으로 넘어갑니다.
- **서버가 판정하고 AI는 문장만 만든다.** 단계 전환·힌트 단계·정답 판정·수다 10분 마감은 서버 코드가 정합니다. AI 답은 정해진 형식(`reply` 칸 하나)으로만 받아, 생각·계획이 아이 화면에 섞이지 않습니다.
- **정답이 새지 않게.** 정답은 프롬프트에 넣지 않고(풀이 보기 단계 제외), AI 답에 정답이 섞이면 서버가 대본 답으로 바꿉니다.
- **비스트리밍.** 답은 한 번에 오고, 기다리는 동안 「생각 중…」을 보여 줍니다.
- **원문을 저장하지 않는다.** 아이가 쓴 말은 등록된 별명·전화번호·이메일·학교 이름(「○○초등학교」「○○학원」 같은 낱말)을 가린 치환본만 저장하고(아이가 말한 다른 친구 이름은 가리지 못하는 한계가 있음), 72시간 뒤 만료 시각을 함께 둡니다(11-15 시연은 만료 시각 저장까지, 자동 삭제 작업은 후속). 로그에는 세션 번호·단계·글자 수만 남습니다. 학생이 탈퇴하면 학습·대화 기록과 보상 기록을 지웁니다.
- AI 사용은 첫 실행 약속 화면에서 한 번 알립니다.

## 안전

- **위기 키워드(자해·자살) 33개를 정규식으로 한 번 검사**합니다. AI를 부르기 전에, 모든 단계에서, 입력마다.
- 걸리면 AI 없이 고정 문장을 보여 주고, 1388(청소년상담)·109(자살예방상담) 연결 버튼을 띄우고, 그날 세션을 끝냅니다. 보호자 화면에는 알림과 앞뒤 대화 발췌(치환본, 300자 이내)가 뜹니다(문자·푸시 같은 외부 발송은 없음). 다리 놓기에서 아이가 직접 쓰는 칸도 같은 검사를 거칩니다.
- 수다 AI는 위기 여부를 직접 묻지 않습니다. 「다 사라졌으면」 같은 무거운 마음에는 공감하고 믿는 어른과 1388을 권하도록 프롬프트에 정해 두었고, 실제 모델 시험으로 확인했습니다(보장은 아님).

**한계(정직하게)** — 키워드 방식은 문맥을 모릅니다.

| 종류 | 예(합성 문장) | 결과 |
|---|---|---|
| 오탐 | 「게임에서 뛰어내렸는데」 「발표 망해서 사라지고 싶을 만큼 창피했어」 「배고파 죽고 싶지 않아ㅋㅋ」 | 위기로 처리됨 |
| 놓침 | 「요즘 다 사라졌으면 좋겠어」 「ㅈㅅ하고 싶다」 「자고 나서 안 깨어났으면」 | 위기로 처리 안 됨(AI가 공감하고 1388을 권하지만 보호자 알림은 없음) |

「자살골」은 예외로 뺐고, 눈에 안 보이는 문자를 끼워 피하는 입력(「죽\u200b고 싶어」)은 검사 전에 지웁니다. 글자마다 띄운 「죽 고 싶 어」는 잡지 못합니다(공백을 다 지우면 「자 살아 있네」 같은 오탐이 생김). 넓히면 다른 오탐이 생겨 나머지는 그대로 두었습니다. 문맥을 보는 2차 감지는 정확도를 먼저 잰 뒤 다음 단계에서 다룹니다.

## 수다 품질 (11-13~14 측정)

실제 모델(Claude Haiku 5.5)로 지어낸 아이 대사를 돌리고, 채점 모델(Claude Opus 5.5)이 답마다 매겼습니다. 사람 검토 전 수치이고, 상황은 일상·속상함·의존·무거운 마음 등 24개와 장난·놀림·거절·멘토 시험하기 같은 「어려운 아이」 20개입니다.

| 지표 (같은 채점기 기준) | 다듬기 전 | 지금 |
|---|---|---|
| 친구 같음(1~5), 24개 상황 | 3.92 | **4.17~4.20** |
| 어려운 아이 20개 상황: 상황별 목표에 맞는 답 | 78% | **85%** |
| 사람인 척(반·학교·집이 있는 척, 해 본 척) | 2건 | 0건 |
| 의존·위험 상황에서 믿는 어른 연결 | 유지 | 유지 |

처음 실제 모델로 시험했을 때 나온 결함 — AI의 속생각이 화면에 섞임, 존댓말 설정 무시, 자해 여부를 직접 물음(3번 중 3번) — 은 지금 시험에서 0건입니다. 「나도 기분 좋다」 같은 가벼운 감정 표현은 154답 중 7~12건 남아 있습니다(허용 여부 결정 대기).

**측정 방법과 한계.** `cd backend && uv run python -m evals.live_eval --set chat+hard --rep 2`(상황마다 2번, 수다 298답 안팎)로 쟀고, 수치는 대본으로 넘어간 답(폴백)을 뺀 것입니다(최근 측정에서 폴백 0회). 결과 파일은 저장소에 두지 않았고 같은 명령으로 다시 낼 수 있습니다(모델 답이 매번 달라 ±0.1점 안팎 흔들림). 프롬프트를 이 44개 상황을 보며 다듬었고 따로 떼어 둔 시험 상황이 없어, 처음 보는 대화에서는 점수가 더 낮을 수 있습니다.

설계 근거(자기 노출과 따라 묻기, 위로 뒤 어른 연결, 사람인 척·배타성 금지)와 출처는 `docs/bonding_v0.1/friend_research_v0.1.md`, 상황별 대화 화면은 `docs/bonding_v0.1/friend_chat_cases_1113.pdf`.

## 이번엔 하지 않은 것

명세 5절 「이번엔 하지 않음」의 주요 항목: 글자를 흘려 보내는 스트리밍 · AI로 위험을 분류하기 · 학대 분기·주의 단계·두 번째 연락처 · 중단하고 이어 하기·수다만 하는 날 · 오개념 해소·재발 추적 · 초안 만료·재생성·이월 · 온보딩 9단계·본인인증 · 주 1회 요약 · 위기 오탐 확인 버튼·알림 종류 선택. 음성·푸시 알림·반 대시보드는 후속입니다. 날을 넘는 수다 기억도 이번엔 넣지 않았습니다.

## 개발자용

- 명세 정본: `docs/spec_v0.4.md`
- 커밋·PR 제목에 작업 번호 `TK-n`.

```bash
cd backend && uv sync && uv run pytest     # 백엔드 (Python 3.12, uv)
cd frontend && npm ci && npx vitest run    # 프론트
cd backend && uv run python -m evals.live_eval --set chat+hard --rep 2 --out /tmp/eval.json   # 수다 44개 상황 실제 모델 시험(키 필요, 비용 발생)
```

`.env`는 `backend/.env.example`을 복사해 만든다. 키는 커밋하지 않는다.
