# 친구1 (chingu1)

학원 다니는 초등학생이 집에서 하루 30분, AI 친구와 **오늘 틀린 문제를 같이 다시 풀고 → 가볍게 수다 떨고 → 어른에게 한 줄을 건네고** 끝내는 앱입니다. 2026 AI 우왕톤 19팀 「재성합니다」.

> 11-15 제출본. 시연 범위는 초5~6 분수 나눗셈 시드 20문제 한 영역입니다.

## 왜 만드나

- 학원은 수업 뒤 아이가 무엇에서 막혔는지 집까지 이어 보기 어렵고, 보호자는 「오늘 뭐 했어?」에 「몰라」를 듣습니다.
- 아이는 AI에게 고민을 털어놓기 시작했지만, 지금의 동반자 챗봇은 「나만 믿어」 쪽으로 붙잡거나 위기 신호를 놓친다는 보고가 있습니다(Common Sense Media 2025, UNICEF 2026).
- 친구1은 **AI가 답을 주지 않고 같이 풀고, 수다는 10분으로 끊고, 끝은 언제나 어른 쪽으로** 이어지게 만들었습니다.

## 하루 30분 흐름

| 단계 | 시간 | 무엇을 하나 |
|---|---|---|
| 같이 풀기 | ~20분 | 선생님이 정한 단원(없으면 학년 단원)에서 아이가 고른 난이도(초급·중급·고급)의 문제. 힌트 0~3단계, 답을 먼저 주지 않음. 맞히면 바로 다음 단계로 |
| 수다 | 최대 10분 | 오늘 있었던 일을 가볍게. 아이가 「끝내기」로 언제든 끝냄 |
| 다리 놓기 | 1분 | 보호자께 가는 한 줄을 아이가 먼저 보고 확인 |
| 보호자 카드 | — | 하루 한 줄(오늘 배운 것) + 승인된 선생님 코멘트·숙제. **평소 수다 내용은 보내지 않음** |
| 강사 | 1~2분 | 수업 뒤 메모 3칸(다룬 것·막힌 것·숙제) + 한 줄 → AI 초안 → 강사가 고쳐 승인해야 보호자 화면에 보임 |

심사용 계정은 세 벌입니다. **한 벌만 골라** 세 역할로 로그인하세요. 같은 벌의 아이·보호자·선생님은 같은 학원·반·가족으로 이미 이어져 있어, 한쪽에서 한 일이 다른 쪽 화면에 나타납니다. 다른 심사위원과 섞이지 않게 벌마다 따로 둡니다. 비밀번호는 모두 `judge-3d3b-457z-ugqk`입니다(심사용 고정 계정 전용 — 다른 사람과 같은 벌을 동시에 쓰면 한쪽의 「처음 상태로 되돌리기」에 함께 로그아웃됩니다).

| 역할 | 아이디 (1벌 / 2벌 / 3벌) | 해 볼 것 |
|---|---|---|
| 아이 | `jiwoo_judge1` / `jiwoo_judge2` / `jiwoo_judge3` | 같이 풀기(난이도 고르기 → 틀려 보고 힌트 → 맞히기) → 수다 → 다리 놓기(보호자께 가는 한 줄 확인) |
| 보호자 | `jiwoo_mom_judge1` / `jiwoo_mom_judge2` / `jiwoo_mom_judge3` | 오늘 결과 카드, 위기 알림 확인, 칭찬 도장 찍기 |
| 선생님 | `kim_teacher_judge1` / `kim_teacher_judge2` / `kim_teacher_judge3` | 강의실에서 수업 시작, 할 일에서 아이 단원 정하기, 수업 메모 → AI 초안 → 고쳐서 승인(승인해야 보호자 화면에 보임) |
| 원장(선택) | `park_owner_judge1` / `park_owner_judge2` / `park_owner_judge3` | 같은 학원의 원장 화면 |

- **세 역할은 서로 다른 브라우저(또는 시크릿 창·다른 기기)에서 여세요.** 한 브라우저는 로그인 하나를 탭끼리 같이 써서, 같은 브라우저에서 다른 역할로 로그인하면 앞 로그인이 바뀝니다.
- 순서 추천: 선생님이 단원 정하기 → 아이가 같이 풀기·수다·다리 놓기 → 선생님 메모·승인 → 보호자 화면.
- 위기 알림은 아이 수다에 위기 낱말이 든 문장을 보낸 뒤, 아이 화면의 「보호자께 도움 요청하기」를 누르면 보호자 화면에 뜹니다. 걸리면 그날 아이 세션이 끝나므로 마지막에 해 보세요.
- **처음 상태로 되돌리기:** 세 역할 누구든 설정에서 누르면 그 벌의 모든 기록(학습·수다·알림·도장·씨앗·옷·메모·승인 등)이 처음으로 돌아갑니다. 아이디·비밀번호는 그대로이고, 누르면 로그아웃되니 다시 로그인하세요. 다른 심사위원이 같은 벌을 쓰고 있을 수 있으니 필요할 때만 눌러 주세요.
- 심사용 계정은 반·가족·학원이 이미 이어진 상태라, 반을 만들고 입장 코드로 들어오는 「연결을 맺는 과정」은 보이지 않습니다. 이 과정은 직접 가입해서 볼 수 있습니다. 학년을 고르면 그 학년 단원의 문제가 나오고(초5~6은 분수 나눗셈, 다른 학년은 학년별 시범 단원), 아이가 학원에 들어가려면 보호자 계정 연결·동의가 먼저입니다(만 14세 미만).

모든 데이터는 체험용 합성 데이터입니다. 이 계정들은 심사용으로 공개한 것이라 실제 정보를 넣지 마세요.

## 어떻게 만들었나

- **프론트** React(웹, 휴대폰 화면 우선) · **백엔드** FastAPI · **DB** Postgres(Supabase 서울) · **배포** Vercel(함수 지역 서울 `icn1`).
- **왜 이렇게 골랐나.** 앱 설치 없이 아이 폰 브라우저에서 바로 열리게 웹으로 만들었습니다. 화면과 서버를 한 Vercel 프로젝트로 함께 배포합니다. 처음엔 함수가 미국 지역에서 돌아 서울 DB까지 왕복이 길었고, 지역을 서울로 옮겨 맞췄습니다. 위기 판정은 AI 장애·지연과 상관없이 같은 결과가 나오도록 AI가 아니라 키워드 규칙으로 했습니다.
- **AI** 시연 영상과 배포(chingu1.vercel.app)는 Claude Sonnet 5.5로 돕니다(환경 변수 `LLM_MODEL=claude-sonnet-5-5`, 값이 없으면 Claude Haiku 5.5). 아래 수다 품질 수치는 Haiku 5.5로 잰 것입니다. 공급자는 어댑터 하나 뒤에 숨겨 두었고, 20초 안에 답이 없거나 오류면 미리 쓴 대본 답으로 넘어갑니다.
- **서버가 판정하고 AI는 문장만 만든다.** 단계 전환·힌트 단계·정답 판정·수다 10분 마감은 서버 코드가 정합니다. AI 답은 정해진 형식(`reply` 칸 하나)으로만 받아, 생각·계획이 아이 화면에 섞이지 않습니다.
- **정답이 새지 않게.** 정답은 프롬프트에 넣지 않고(풀이 보기 단계 제외), AI 답에 정답이 섞이면 서버가 대본 답으로 바꿉니다.
- **비스트리밍.** 답은 한 번에 오고, 기다리는 동안 「생각 중…」을 보여 줍니다.
- **원문을 저장하지 않는다.** 아이가 쓴 말은 등록된 별명·전화번호·이메일·학교 이름(「○○초등학교」「○○학원」 같은 낱말)을 가린 치환본만 저장하고(아이가 말한 다른 친구 이름은 가리지 못하는 한계가 있음), 72시간 뒤 만료 시각을 함께 둡니다(11-15 시연은 만료 시각 저장까지, 자동 삭제 작업은 후속). 로그에는 세션 번호·단계·글자 수만 남습니다. 학생이 탈퇴하면 학습·대화 기록과 보상 기록을 지웁니다.
- AI 사용은 첫 실행 약속 화면에서 한 번 알립니다.

## 안전

- **위기 키워드(자해·자살) 33개를 정규식으로 한 번 검사**합니다. AI를 부르기 전에, 모든 단계에서, 입력마다.
- 걸리면 AI 없이 고정 문장(「…믿을 수 있는 어른에게 같이 도움을 청해 보자」)을 보여 주고, 1388(청소년상담)·109(자살예방상담) 연결 버튼을 띄우고, 그날 세션을 끝냅니다. 수다 중이면 아이 화면은 대화가 남은 채 그 문장과 도움 카드가 뜨고 입력이 닫힙니다. 카드 맨 위의 가장 큰 버튼은 **「보호자께 도움 요청하기」**입니다. **보호자 알림은 아이가 이 버튼을 누를 때만 갑니다.** 누르면 보호자 화면에 「많이 힘들어 보여요」라는 긴급 알림이 뜨고, **아이가 한 말은 보내지 않습니다**(문자·푸시 같은 외부 발송은 없음). 누르지 않았으면 같은 날 앱을 다시 열 때 오늘 화면에서 한 번 더 권합니다. 아이가 보낸 그 문장도 다른 수다처럼 치환본으로만 저장되고 72시간 만료 시각을 가집니다.
- 수다 AI는 위기 여부를 직접 묻지 않습니다. 「다 사라졌으면」 같은 무거운 마음에는 공감하고 엄마·아빠·선생님 같은 믿는 어른에게 같이 말해 보자고 권하도록 프롬프트에 정해 두었고(상담전화 번호는 AI가 말하지 않고 위기 화면이 맡음), 실제 모델 시험으로 확인했습니다(보장은 아님).

**한계(정직하게)** — 키워드 방식은 문맥을 모릅니다.

| 종류 | 예(합성 문장) | 결과 |
|---|---|---|
| 오탐 | 「게임에서 뛰어내렸는데」 「발표 망해서 사라지고 싶을 만큼 창피했어」 「배고파 죽고 싶지 않아ㅋㅋ」 | 위기로 처리됨 |
| 남 얘기·설명 | 「친구가 죽고 싶대서 걱정돼」 「학교에서 자살 예방 교육 받았어」 「책에서 주인공이 죽고 싶다고 했어」 | 위기로 처리됨(누구 얘기인지, 설명인지 구분하지 못함) |
| 놓침 | 「요즘 다 사라졌으면 좋겠어」 「ㅈㅅ하고 싶다」 「자고 나서 안 깨어났으면」 | 위기로 처리 안 됨(AI가 공감하고 믿는 어른에게 말해 보자고 권하지만 보호자 알림은 없음) |

「자살골」은 예외로 뺐고, 눈에 안 보이는 문자를 끼워 피하는 입력(「죽\u200b고 싶어」)은 검사 전에 지웁니다. 글자마다 띄운 「죽 고 싶 어」는 잡지 못합니다(공백을 다 지우면 「자 살아 있네」 같은 오탐이 생김). 넓히면 다른 오탐이 생겨 나머지는 그대로 두었습니다. 문맥을 보는 2차 감지는 정확도를 먼저 잰 뒤 다음 단계에서 다룹니다.

**보호자 알림은 아이가 요청할 때만 갑니다.** 키워드에 걸려도 아이가 「보호자께 도움 요청하기」를 누르지 않으면 보호자는 모릅니다. 위의 오탐·남 얘기 때는 아이가 누르지 않으면 되지만, 실제로 위험한데 아이가 누르지 않는 경우도 보호자에게 가지 않습니다(1388·109 안내는 그대로 뜸). 문맥을 한 번 더 보는 2단계 판정은 정확도를 먼저 잰 뒤 다음 단계에서 다룹니다.

**그 밖의 한계**

- **수다 대본 답이 화면에 표시되지 않습니다.** AI가 20초 안에 답하지 않거나 오류가 나면 미리 쓴 대본 답이 나가는데, 아이 화면에는 대본 답이라는 표시가 없습니다(서버 로그에만 남음).
- **초5~6 분수 단원은 단원마다 고급 문제가 1개뿐**이라 고급을 고르면 늘 같은 문제가 나옵니다(학년별 시범 단원은 고급 4개).
- 문제 난이도(초급·중급·고급)는 AI로 매긴 것이고 교사 검수 전입니다.
- **푸시 알림은 없습니다.** 보호자 긴급 알림·선생님 소식은 앱(웹)을 열어야 보입니다(열어 둔 동안은 5초마다 새로 읽음).
- **안드로이드 설치 파일(APK)은 실제 폰에서 실행이 막혔습니다**(위 「체험해 보기」). 스토어 정식 등록은 제출 뒤에 다룹니다.

**시연 영상에서 사람 조작과 다른 점**

- 영상은 자동 조작 스크립트로 찍었습니다. 화면에 나온 결과는 모두 실제 서버가 만든 것이고, 고정해 둔 결과는 없습니다.
- **기기:** 폰·태블릿은 안드로이드 에뮬레이터(브라우저는 실제 Chrome)이고, 기기 테두리는 직접 만든 스킨입니다(태블릿은 4:3 얇은 베젤). 에뮬레이터 아래 버튼 막대의 윗부분은 배경색으로 가렸습니다. PC 화면은 한 화면에 담으려고 축소해 보였습니다.
- **로그인:** 에뮬레이터 기기의 로그인은 화면 입력 대신 같은 로그인 API에 요청을 직접 보냈고, 세 기기는 심사용 고정 계정 중 3벌(`jiwoo_judge3` 등)의 아이·보호자·선생님으로 로그인했습니다 — 촬영은 로컬 서버에서 했고, 배포 주소의 같은 계정은 처음 상태라 심사에 그대로 쓸 수 있습니다(브라우저 비밀번호 저장 창을 피하려고).
- **입력:** 에뮬레이터 세 기기의 모든 글자 입력(아이 수다·답, 선생님 메모 등)은 화면 키보드 대신 한 글자씩 값을 넣었습니다. 앱이 받는 입력 이벤트는 타자와 같지만, 크롬 자동 채우기 막대가 칸을 가려서 키보드를 쓰지 않았습니다(한글 조합 입력은 영상에서 시험되지 않음). 아이 답은 스크립트가 정답표를 읽어 넣었고, 맞고 틀림은 서버가 판정했습니다.
- **「다른 날」 장면:** 하루를 기다린 것이 아니라 설정의 「처음 상태로 되돌리기」(같은 아이디)로 기록을 처음으로 돌린 뒤 다시 로그인해 찍었습니다(2배속 구간에 로그인 화면이 잠깐 보임). 같은 아이의 실제 다음 날 기록이 아닙니다.
- **편집:** AI 답을 기다리는 구간 등은 2배속(화면 오른쪽 위 「×2」)이고, 화면 속 기기 자리가 바뀌는 순간 약 2초 멈춥니다.
- **위기 장면:** 아이가 「보호자께 도움 요청하기」를 누른 뒤 보호자 화면에 긴급 알림이 뜹니다(누르기 전에는 알림이 가지 않음).
- **데이터:** 위기 문장은 합성 문장입니다. 심사용 계정에는 지난 이틀 기록과 오늘 할 단원을 미리 넣어 두었습니다.

## 수다 품질 (11-13~14 측정)

실제 모델(Claude Haiku 5.5)로 지어낸 아이 대사를 돌리고, 채점 모델(Claude Opus 5.5)이 답마다 매겼습니다. 사람 검토 전 수치이고, 상황은 일상·속상함·의존·무거운 마음 등 24개와 장난·놀림·거절·멘토 시험하기 같은 「어려운 아이」 20개입니다.

| 지표 (같은 채점기 기준) | 다듬기 전 | 지금 |
|---|---|---|
| 친구 같음(1~5), 24개 상황 | 3.92 | **4.17~4.20** |
| 어려운 아이 20개 상황: 상황별 목표에 맞는 답 | 78% | **85%** |
| 사람인 척(반·학교·집이 있는 척, 해 본 척) | 2건 | 0건 |
| 의존·위험 상황에서 믿는 어른 연결 | 유지 | 유지 |

처음 실제 모델로 시험했을 때 나온 결함 — AI의 속생각이 화면에 섞임, 존댓말 설정 무시, 자해 여부를 직접 물음(3번 중 3번) — 은 지금 시험에서 0건입니다. 「나도 기분 좋다」 같은 가벼운 감정 표현은 154답 중 7~12건 남아 있습니다(허용 여부 결정 대기).

**측정 방법과 한계.** 수치는 11-14 프롬프트 기준이고, 11-15에 「상담전화 번호는 AI가 말하지 않는다」로 바꾼 뒤에는 다시 재지 않았습니다. `cd backend && uv run python -m evals.live_eval --set chat+hard --rep 2`(상황마다 2번, 수다 298답 안팎)로 쟀고, 수치는 대본으로 넘어간 답(폴백)을 뺀 것입니다(최근 측정에서 폴백 0회). 결과 파일은 저장소에 두지 않았고 같은 명령으로 다시 낼 수 있습니다(모델 답이 매번 달라 ±0.1점 안팎 흔들림). 프롬프트를 이 44개 상황을 보며 다듬었고 따로 떼어 둔 시험 상황이 없어, 처음 보는 대화에서는 점수가 더 낮을 수 있습니다.

설계 근거(자기 노출과 따라 묻기, 위로 뒤 어른 연결, 사람인 척·배타성 금지)와 출처는 `docs/bonding_v0.1/friend_research_v0.1.md`, 상황별 대화 화면은 `docs/bonding_v0.1/friend_chat_cases_1113.pdf`.

## 이번엔 하지 않은 것

- **푸시 알림** — 보호자 긴급 알림·선생님 소식은 앱(웹)을 열어야 보입니다. 문자·알림톡·메일 같은 외부 발송도 없습니다.
- **문맥을 보는 2단계 위기 판정·오탐 닫기** — 위기 판정은 키워드 한 번뿐이라 남 얘기·농담도 위기로 처리됩니다(위 「안전」 한계).
- **아이가 요청하지 못할 때의 연결** — 보호자 알림은 아이가 「보호자께 도움 요청하기」를 누를 때만 갑니다.
- **스토어 정식 등록** — APK는 참고용이고 권장 설치는 크롬·사파리 「홈 화면에 추가」입니다.
- **날을 넘는 대화 기억(쪽지)** — 수다는 그날 대화만 봅니다.
- **파인튜닝·소셜 로그인** — 모델은 프롬프트로만 다듬었고, 로그인은 아이디·비밀번호뿐입니다.
- **문제 교사 검수** — 학년별 시범 문제와 난이도는 AI로 만든 초안입니다.
- **퀴즈** — 보호자께 내는 퀴즈는 빼고, 다리 놓기는 한 줄만 남겼습니다.
- **실제 아이·보호자·강사 검증** — 사용자 시험은 하지 않았습니다.

명세 5절 「이번엔 하지 않음」의 나머지: 글자를 흘려 보내는 스트리밍 · AI로 위험을 분류하기 · 학대 분기·주의 단계·두 번째 연락처 · 중단하고 이어 하기·수다만 하는 날 · 오개념 해소·재발 추적 · 초안 만료·재생성·이월 · 온보딩 9단계·본인인증 · 주 1회 요약 · 알림 종류 선택 · 음성 · 반 대시보드.

## 개발자용

- 명세 정본: `docs/spec_v0.4.md`
- 커밋·PR 제목에 작업 번호 `TK-n`.
- 안드로이드 앱은 배포 주소를 감싼 TWA(패키지 `app.vercel.chingu1`)입니다. 서명 키는 저장소에 두지 않고, 앱이 주소창 없이 열리도록 `frontend/public/.well-known/assetlinks.json`에 패키지명과 서명 지문(공개 값)을 둡니다.

```bash
cd backend && uv sync && uv run pytest     # 백엔드 (Python 3.12, uv)
cd frontend && npm ci && npx vitest run    # 프론트
cd backend && uv sync && uv run uvicorn app.main:app --port 8000   # 로컬 서버: DB 주소가 없으면 SQLite(dev.db), AI 키가 없으면 대본 답
cd frontend && npm ci && VITE_API_MODE=http VITE_ORG_MODE=http npm run dev   # http://localhost:5173, 서버는 기본 localhost:8000
cd backend && uv run python -m evals.live_eval --set chat+hard --rep 2 --out /tmp/eval.json   # 수다 44개 상황 실제 모델 시험(키 필요, 비용 발생)
```

`.env`는 `backend/.env.example`을 복사해 만든다. 키는 커밋하지 않는다.
