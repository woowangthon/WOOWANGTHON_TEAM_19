# DESIGN.md — AI 멘토 디자인·UI 규칙 (v0.7, 2026-11-13)

> 작성: 재하(프론트·디자인 담당). 디자인은 **재하 + GPT**가 맡는다.
> **코드가 기준이다.** 문서와 코드가 다르면 코드가 최신이므로 문서를 고친다. 화면을 바꾼 커밋에는 이 문서의 해당 장과 맨 아래 「16. 변경 기록」도 같이 고친다.
> 이 문서를 읽는 Claude·팀원은 **디자인을 새로 정하지 않는다.** 기존 부품으로 조립하고, 새 디자인이 필요하면 맨 아래 **요청서 양식**으로 재하에게 보낸다.
> 경로는 프론트엔드 폴더 기준: 값 `src/styles/tokens.css`, 모양 `src/styles/global.css`, 부품 `src/components/`

---

## 1. 누구를 위한 앱인가
- 학원에 다니는 학생이 집에서 개인 휴대폰으로 **하루 30분**: 문제 20분 → (선택) 수다 10분 → 마무리.
  - 가입 학년: **초1~고3**(학교급 → 학년 두 단계로 고름). 멘토 말투는 학년대(초1-2·초3-4·초5-6·중·고)에 맞춘다.
  - 시연 문제·범위는 지금 **초등 4학년 수학**(분수). 화면 기준 사용자는 여전히 초등 고학년.
- 학원 쪽(학습지도자)은 **학원 태블릿·선생님 PC**에서도 쓴다(3장 넓은 화면).
- 멘토는 **답부터 알려 주지 않고 힌트로 돕는 형·언니** 같은 존재.
- 톤: 초등 고학년에게 **유치하지 않게**. 어른(보호자·학습지도자) 화면은 **차분한 정보 중심**.

## 2. 바꿔도 되는 것 / 안 되는 것
| 바꿔도 됨 (디자인 담당) | 바꾸면 안 됨 (모두) |
|---|---|
| `tokens.css`의 **값**(색·크기·간격·모서리) | 변수 **이름**(`--color-primary` 등) |
| `global.css`의 모양(그림자·여백·동작) | 기존 **클래스 이름**(화면 코드가 사용 중) |
| `.tsx`의 배치(마크업 순서·감싸는 요소) | `src/api/`, `src/state/`, 화면의 `api.` 호출·조건 로직 |
| 새 클래스 추가 | 버튼 문구의 **의미**(다듬기는 가능) |

- `.tsx`를 고쳤다면 `npm run typecheck && npm test` 통과 필수.
- **디자인 담당이 아닌 사람(Claude 포함)**: `tokens.css` 값, `global.css` 기존 모양, `public/mascot/` 그림을 바꾸지 않는다. 새 색·새 글꼴을 들이지 않는다.

## 3. 화면 공통
- 세로 **9:16, 기준 360×640**(휴대폰). 화면 폭에 따라 틀이 바뀐다(`global.css` 「휴대폰·태블릿·PC 틀」):

| 폭 | 틀 |
|---|---|
| 휴대폰 ~599px | 꽉 찬 한 줄 화면 + 하단 탭 |
| 태블릿 600~1023px | 화면을 꽉 채우고 하단 탭 → **왼쪽 아이콘 레일**. 내용은 가운데(아이 720px · 어른 960px). 시트는 가운데 대화상자 |
| PC 1024px~ | 레일 → **이름 붙은 사이드바**. 목록은 카드 격자(`.card-grid`) |

  - 학습지도자는 폭과 상관없이 폰 틀 없이 창 전체(`.frame--wide`, `lib/wide.ts`). PC에서 「할 일」은 왼쪽 학생 목록 + 오른쪽 상세(`.teacher-split`), 「결과」는 표(`.table--results`).
  - 주소에 `?frame=phone`을 붙이면 예전처럼 가운데 폰 프레임(360×640)으로 본다 — **시연 영상 촬영용**.
- 상단바: 뒤로가기 / 화면 이름 / 작은 "AI 멘토" 라벨 / 오른쪽 보조 아이콘.
- 탭 첫 화면: 뒤로가기 없음. **왼쪽 위 설정(톱니), 오른쪽 위 알림함(종, 안 읽은 수 = 머스터드 숫자)**.
- **주요 버튼은 아래 엄지 영역**(`Frame`의 `actions`), 한 화면에 주요(민트) 버튼 1개. 스크롤이 생겨도 항상 보이게.
- 누르는 곳 최소 **44×44px**, 입력칸 높이 46px 이상.
- 입력창 옆 `+` 버튼 금지(수학식의 +는 유지).
- 이모지 대신 **선 아이콘**(`Icon` 컴포넌트).
- 로그인·가입·풀이·수다·첫 실행(약속 → 캐릭터 고르기) 화면에는 하단 탭을 숨긴다. 첫 실행은 단계 표시(1/2, 2/2).

## 4. 색
| 토큰 | 용도 |
|---|---|
| `--color-primary` 민트 | 주요 버튼, 선택됨, 진행 |
| `--color-accent` 머스터드 | 연속 일수, 씨앗 테두리, 주의 안내, 오답 |
| `--color-bg` 크림 | 바탕 |
| `--color-danger` 빨강 | **긴급 안전 알림에만** |
| `--adult-*` | 어른 화면(같은 팔레트, 저채도). `Frame adult` |

- **보라색 쓰지 않음.**
- 둥근 모서리 + **버튼 아래 같은 색 계열 그림자**(눌리는 느낌).
- 정답·오답을 빨강으로 표시하지 않는다. 오답은 머스터드 + 괜찮다는 표정("아깝다! 여기까지는 맞았어").
- 캐릭터 고르기 카드 구분: 진한 민트 / 머스터드 / 크림(+작은 포인트).
- 어른 화면에서 캐릭터는 로고 크기만.

## 5. 글자
- 본문 16 / 제목 20 / 큰 제목 24 / 키패드 22 / 보조 13.
- 학생 화면 보조 글자는 **13px 아래로 줄이지 않는다**(초등 학생 가독성).
- 숫자는 `.num`(고정폭 숫자).

## 6. 역할별 하단 탭
| 역할 | 탭 |
|---|---|
| 학생 | 오늘 · 기록 · **강의실** · 내 멘토 (상점은 「내 멘토」 옷장 → 상점, 오늘 화면 씨앗 칩) |
| 학습지도자 | 범위 · 할 일 · **강의실** · 결과 · 씨앗 (「긴급 알림」 입구는 11-15에 **숨김** — 🔴 알림이 보호자에게만 가서 늘 비어 있음. 화면 `/teacher/alerts`는 후속용으로 남김) |
| 보호자 | 결과(내 아이만) · 알림 |
| 운영자 | 탭 없음 |
- 원장은 별도 역할이 아니다: 학원·학교를 등록해 승인받은 **학습지도자**. 「설정 → 학원 관리」로 들어간다.

### 6-1. 강의실 수업 진행 (11-13)
| 누가 | 화면 | 하는 일 |
|---|---|---|
| 원장 | 학원 관리 | 강의실 만들기 · 담당 학습지도자 · 장소(선택). 「수업 기본값」: 수업 40/50/60분 · 쉬는 시간 5/10/15분 · 켜기/끄기(쉬는 시간 게임 · 보호자에게 수업 상태 알리기 · 강의실 장소 표시, 장소는 기본 꺼짐) |
| 학습지도자 | 강의실 카드 | 「수업 시작 · N분」 → 끝나는 시각 · 남은 분 · −5분/+5분 · 쉬는 시간 · 수업 다시 시작 · 수업 끝내기 · **수업 참여 목록**(「참여 취소」로 바로 뺌). 강의실은 직접 만들지 않는다(+ 버튼 없음) |
| 학생 | 강의실 카드 | 수업 중이면 「수업 참여」 → **수업 모드**: 수다 · 내 멘토(옷장) · 상점이 잠긴다(탭에 자물쇠, 누르면 잠금 안내). 화면 위 띠 「수업 중 · ○시에 끝나」. 쉬는 시간엔 풀리고 「쉬는 시간 게임」 |
| 보호자 | 결과(첫 화면) | 수업 상태 카드: 수업 중 · 끝나기 N분 전 · 쉬는 시간 · 끝났어요(30분까지) + 장소. 픽업용 |
- 알림 시점은 고정: 끝나기 **5분 전 + 끝날 때**(학습지도자·보호자 — 보호자는 예정 시각과 「수업 끝내기」를 누른 때 둘 다), 학생은 수업 시작 · 쉬는 시간 시작 · 쉬는 시간 끝나기 1분 전. 화면에 4초 떴다 사라짐(`.timer-toast`, 머스터드 안내, 누를 수 없음).
- 모양(GPT-037~048): 원장 설정 행 `.session-setting`+`.switch`(켜짐/꺼짐 글자), 강의실 `.classroom-meta`·`.classroom-form`, 수업 진행 `.session-start`·`.session-adjust`·`.session-actions`·`.session-end`(끝내기는 아래로 떨어뜨린 ghost), 여러 강의실이면 첫 카드만 주요색(`.session-room`), 참여 목록 `.joined-list`·`.joined-row`, 학생 `.student-session`, 탭 `.tab--locked`+「잠김」(누르면 잠금 안내 — 막지 않음), 잠금 화면 `.locked-mentor`(아이가 고른 멘토 얼굴)+`.safety-link`, 게임 `.game-choice`·`.pairs-card`·`.guess-form`·`.reaction-pad`, 보호자 `.guardian-session`(시각 24px).
- 「수업 참여」는 **출석이 아니다** — 화면에서 「출석」이라고 부르지 않는다.
- 서버 전이라 이 기기(브라우저)에만 저장(`lib/classSession.ts`). 다른 기기와 맞추려면 서버 필요.

## 7. 계정 화면 구성 (일반 앱 관례)
| 화면 | 구성 |
|---|---|
| 로그인 | 캐릭터·앱 이름 → 아이디 → 비밀번호(보기 토글) → 자동 로그인 체크 → 로그인 → `아이디 찾기 \| 비밀번호 찾기 \| 회원가입` → (맨 아래 작게) 체험 계정 |
| 회원가입 | 3단계 + 진행 막대: ① 누구인가요(학생·보호자·학습지도자) ② 약관(전체 동의, [필수]/[선택], 보기) ③ 정보(아이디 중복 확인, 비밀번호·확인, 이름, 학생=학년[학교급 칩 → 학년 칩이 아래에서 나타남] / 어른=이메일) → 가입 완료 안내 |
| 찾기 | 탭: 아이디 찾기(이메일) / 비밀번호 찾기(아이디+이메일). 학생은 "보호자가 재설정" 안내 |
| 설정 | 프로필 카드 → 역할별 묶음 → 계정(프로필·비밀번호·알림) → 고객 지원(공지·FAQ·문의) → 약관·정보(이용약관·개인정보·버전) → 로그아웃 → 회원 탈퇴(작게) |
| 알림함 | 최신순, 안 읽은 것은 머스터드 점, 누르면 관련 화면 |
- 입력 칸 도움말: `.hint`(회색) / `.hint--ok`(민트, 통과) / `.hint--bad`(머스터드, 다시). **빨강 쓰지 않음.**

## 9. 캐릭터 그림
- **띠(십이지신) 캐릭터 12종**(11-13): `rat ox tiger rabbit dragon snake horse sheep monkey rooster dog pig`(고르는 순서도 이대로). 그림체 **B 부드러운 플랫**. 띠는 아이가 고르는 캐릭터일 뿐 — 성격·능력과 연결하지 않고 생년을 묻지 않는다.
- 표정·옷·이모티콘까지 다 있는 동물은 `FULL_ART_ANIMALS`(지금 말·원숭이). 나머지 10종은 인사(wave)만 있어 다른 표정 자리에 인사 그림을 쓰고, 옷·이모티콘은 자리표시(GPT 요청서 GPT-049~053).
- 따뜻한 갈색 털 + 청록·머스터드 포인트, 10~12세 대상, 형·언니 같은 멘토.
- 경로: `public/mascot/{animal}/`

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `{mood}.png` | 512×512 투명, 전신 | 96px 초과 |
| `{mood}-face.png` | 상반신 | 57~96px |
| `{mood}-avatar.png` | 머리 | 56px 이하 |
| `outfit-{id}.png` | 전신, **wave 자세** | 옷 입은 캐릭터 |
| `outfit-{id}-face.png` | 상반신, wave | 오늘 화면 머리 그림 |
| `emote-{id}.png` | 256×256 투명 | 상점·이모티콘 |

- mood: `wave`(인사) `think`(생각) `cheer`(칭찬) `promise`(약속) `calm`(차분) `read`(읽기)
- 옷 id: `glasses`(공부 안경) `raincoat`(노란 우비) `scarf`(겨울 목도리) `cape`(별 망토) · 11-13 추가 `cap`(야구 모자) `backpack`(새 책가방) `headphones`(집중 헤드폰) `hanbok`(색동 한복)
- 이모티콘 id: `thumbs`(엄지 척) `thanks`(고마워) `sleepy`(졸려) `best`(최고야) · 11-13 추가 `cheer`(힘내) `question`(궁금해) `idea`(알았다!) `sorry`(미안해)
- 그림이 들어오면 `components/Seed.tsx`의 `COSMETIC_ART`에 적어야 보인다(목록에 없으면 요청하지 않고 자리표시).
- **이름만 맞추면 코드 수정 없이 들어간다.** 파일이 없으면 기본 그림·자리표시(오류 없음).
- 한 장 150KB 이하 권장. 같은 동물은 같은 구도(발끝·머리 위 여백 동일).
- 그림은 **덮어쓰지 않고 새 버전**으로 저장한 뒤 교체.
- 캐릭터 고르기: 앞뒤로 겹친 카드 넘기기 + 아래 **옷장**.
- 말투(스타일 = 같이 풀어주는 / 들어주는 / 짚어주는, 호칭 = 형/언니/친구, 반말/존댓말)는 **첫 실행에서만** 이 화면에서 고른다. 그 뒤엔 「내 멘토」 오른쪽 위 **말풍선 아이콘(`talk`) → 「멘토 말투 설정」 시트**에서만 바꾼다(전체 설정에는 넣지 않음). 「내 멘토」 탭 화면 자체는 캐릭터·옷장만.

## 10. 말투
- 학생 화면 문구는 멘토 말투 설정을 따른다: 코드에서 `say('반말', '존댓말')`.
- 어른 화면은 존댓말 고정.
- 역할 이름은 **학습지도자**(강사 X). 아이에게 보이는 문구는 "선생님"도 됨.
- 정답을 먼저 보여 주지 않는다: 틀리면 힌트(최대 3번) → 그래도 틀리면 「풀이 같이 보기」.

## 11. 아이 안전 — 화면으로 지키는 것
- **평소 수다는 어른 화면에 보이지 않는다.**
  - 보호자: 위험할 때만, 분류 + 긴급도 + 다음 행동 안내. **🔴(자해·자살)일 때만 걱정된 말의 앞뒤 일부(±2턴·300자, 개인정보 가린 본) + 「아이와 대화해 보세요」**를 함께 보인다(결정 11-11 「11-15 안전 알림 전달 수준」). 긴급 닫기는 11-15에 회색 「후속」 버튼(누를 수 없음).
  - 아이에게도 사실대로 알린다: 약속 화면·위기 화면·보호자 동의 문구가 "🔴이면 앞뒤 몇 마디가 보호자에게 간다"를 말한다. "대화 내용은 보내지 않아" 같은 문구를 쓰지 않는다.
  - 학습지도자: 긴급일 때만, 분류 없이 "긴급 확인 필요 · 보호자에게도 전달됨".
- 실수 유형·힌트 수는 학습지도자만. 보호자는 푼 문제·연속 일수·아이가 고른 어려운 점·승인된 코멘트까지.
- 학생 가입에서 진짜 이름·전화번호·이메일을 받지 않는다(아이디·별명·학년만).
- 만 14세 미만: 보호자와 연결 + 보호자 동의 전에는 학원 입장·수다 잠금(화면에 이유 표시).
- **수업 모드에서도 위기 화면·1388·안전 단어는 잠그지 않는다.** 잠금 안내 화면에 「힘든 일이 있으면 여기를 눌러」(→ 위기 화면)를 항상 둔다.
- 보호자 수업 카드는 앱이 확인하지 않은 사실(아이가 교실에 있음)을 말하지 않는다: 「수업 중이에요 · ○○가 수업 참여를 눌렀어요」까지.
- 쉬는 시간 게임은 점수·순위·재화를 저장하지 않는다.

## 12. 씨앗(재화) 표현
- 이름은 **씨앗**. 새싹 아이콘. 돈·동전·보석 모양 X.
- **넣지 않는 것**: 랜덤 뽑기·확률 상품, 현금 충전, 친구와 씨앗 비교(랭킹), "지금 안 사면 사라져요" 같은 재촉.
- **두 재화**(11-12 결정, GPT-009~014 적용 11-13): **씨앗** = 학원 재화(학습 완료 +3 · 선생님 칭찬 → 학원 상품), **칭찬 도장** = 앱 재화(보호자 「이야기 나눴어요」 하루 1번 → 옷·이모티콘). 두 잔액을 합치지 않고 서로 바꾸지 않는다.
- 얻는 방법을 화면에 항상 적는다: 상점 `.seed-hero--dual`·`.wallet-account`, 오늘 화면 `.wallet-help`, 탭마다 `.currency-note`. 오늘 화면 씨앗 칩 → 학원 상품 탭, 도장 칩 → 꾸미기 탭. 학습지도자 씨앗 화면 위 `.academy-currency` + 「도장은 따로」 안내.
- 모자라면 버튼에 "N개 더"(빨강·경고 금지).
- 보호자 도장은 "이야기 **내용 평가**"가 아니라 "이야기를 **나눈 것**"에 — 이 문구를 지우지 않는다.

## 13. 움직임·접근성
- 애니메이션 0.3초 이하, `prefers-reduced-motion`이면 끈다.
  - 지금 있는 움직임: 화면 내용이 살짝 떠오르며 나타남(0.22초), 시트 올라옴(휴대폰)·살짝 커짐(태블릿·PC), 탭 배경 전환, PC에서 카드·탭 마우스 올림, 가입 학년 칩 나타남.
- 색만으로 상태를 구분하지 않는다(글자·아이콘 함께).
- 포커스 테두리(`:focus-visible`) 지우지 않기.

## 14. 디자인 작업 방식 (재하 ↔ GPT)
- GPT는 **값(tokens.css)·모양(global.css)·그림**과, 허락된 범위의 배치(마크업)를 맡는다. 화면 흐름·API 호출 로직은 건드리지 않는다.
- 변수·클래스 **이름은 유지**, 값만 바꾼다.
- 360×640에서 직접 눌러 확인하고, 결과는 번호(GPT-0xx)로 기록한다.
- 배포·git push·노션 수정은 디자인 작업에서 하지 않는다.
- 끝나면 `npm run typecheck && npm test`, 실행본이 필요하면 `npm run build:single`.

## 15. 디자인 요청서 양식 (팀원·Claude → 재하)
새 화면이나 화면 변경이 필요하면 **기존 부품으로 임시 조립**한 뒤, 아래를 채워 재하에게 보낸다. 재하가 GPT 프롬프트로 바꿔 작업한다.

```
[디자인 요청] 제목:
- 화면/경로: (예: /guardian 보호자 결과)
- 왜 필요한가: (기능·회의 결정 근거, BRIEF 항목)
- 들어갈 내용(데이터): (필드 이름과 예시 값, types.ts 기준)
- 사용자 행동: (누르면 무엇이 되는지, 상태: 로딩/빈/오류/완료)
- 지금 임시로 만든 것: (기존 부품으로 조립한 위치·클래스, 스크린샷 경로)
- 꼭 지킬 것: (아이 안전·개인정보 관련 제약)
- 마감:
```
