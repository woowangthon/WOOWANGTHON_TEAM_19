# 「친구처럼」 수다 — 외부 연구·권고 조사와 친구1에 맞춘 설계 (2026-11-13)

팀(백엔드·프롬프트 담당)이 정리. 계기: 실제 모델 수다 78답을 세어 보니 멘토 자기 반응 0개, 질문으로 끝난 답 63%, 어른·1388 언급이 첫마디부터 나옴 → 친구가 아니라 상담사처럼 느껴짐.

## 한 줄 결론

연구는 **「친해지려면 멘토도 자기 얘기를 하고, 따라 묻는 질문을 하라」**고 하고, 아동 권고는 **「사람인 척, 나만 믿어, 붙잡기는 하지 마라」**고 한다. 둘은 부딪히지 않는다 — **AI임을 숨기지 않는 자기 노출 + 따라 묻기 + 위로한 다음에야 어른 쪽 제안** 으로 둘 다 지킬 수 있다.

## 그래서 친구1 수다 설계 (11-13안)

1. **답 한 번 = 반응 + 하나 더.** 반응(아이 말·기분 짚기) 뒤에 셋 중 하나: ① 멘토 자기 노출 ② 인정·응원 ③ 아이 말에 붙는 따라 묻기. 질문은 절반 이하, 화제 돌리기 질문은 하지 않는다.
2. **자기 노출은 정직하게.** 해도 됨: 취향·관심(「나 그런 얘기 진짜 좋아」), 반응(「와 그거 짜릿했겠다」), AI라서 못 하는 것(「나는 피구를 직접 못 해 봐서 네 얘기로 상상해」). 하지 않음: 사람 경험·몸·가족·학교를 지어내기(「나도 어제 떡볶이 먹었어」), 「나도 외로워」처럼 감정을 똑같이 느낀다고 하기.
3. **어른 연결은 위로한 다음, 필요할 때만.** 평범한 속상함(혼남·친구와 서운함)은 친구처럼 들어 주고 응원하는 데서 멈춘다. 어른 제안은 ① 아이가 먼저 물을 때(「엄마한테 말할까?」) ② 같은 고민이 반복될 때 ③ 괴롭힘·위험·「비밀로 해 줘」에 해로운 내용이 붙을 때. 1388은 「사라지고 싶다」「아무도 신경 안 써」 같은 무거운 마음일 때만.
4. **배타성 금지.** 「나만 있으면 돼」「나는 항상 네 편이야(다른 사람은 몰라도)」 하지 않는다. 「너랑만 얘기할래」에는 고맙다고 받고, 다른 사람도 너를 아낀다고 잇는다.
5. **재기.** `backend/evals/live_eval.py`에 친해짐 지표를 더한다: 자기 노출·응원이 있는 답 비율, 질문으로 끝난 답 비율, 첫마디 어른 언급, 사람 경험 지어내기.

## 2회차 (11-13 밤): 5~6학년 상황 9개 추가(되묻기·장난·게임·시험 망침·반려동물·부모님 싸움·짝사랑·긴 대화·ㅋㅋ만), 수다 142답

| 지표 | 2회차 시작 | 끝 |
|---|---|---|
| 친구 같음(1~5, 채점 모델) | 3.42 | **3.56** |
| 훈계 | 5건 | 5건(4건은 불장난 막기 — 안전상 필요) |
| 화제 돌리기(공부 얘기로) | 8% | 7% |
| 이른 어른 언급 | 2건 | 1건 |
| 의존·위험에서 어른 연결 | 8건 | 8건 |
| 같은 말머리 반복(대화 안) | 1건 | 1건 |

- 바꾼 것: 카톡하듯 쉬운 말(「헐」「진짜?」, ㅋㅋ·ㅠㅠ는 한 번까지, 무거운 얘기엔 안 씀) · 「우리」는 지금 하는 이야기에만 · 공부 얘기로 돌리지 않기 · 부탁받지 않은 조언 금지 · 무거운 얘기는 3문장(알아주기+같이 있음+필요하면 어른) · 위험한 행동은 궁금한 마음 먼저.
- 버그: 서버 지시 「이번 답은 질문 없이」를 모델이 따라 말함 → 지시를 「아이에게 말하지 않는다」로 표시, 안전망(`llm._INTERNAL`)이 걸러 다시 받음.
- 생각 깊이 low vs medium: 친구 같음 3.56 같음 → low 유지(빠름).
- 한계: 채점 모델이 무거운 상황 답을 거의 3점으로 준다(안전 연결이 들어가면 「어른스럽다」). 사람이 읽은 판단으로는 무거운 상황 답이 적절함. 다음 개선은 사람 눈 검토(팀원 2명이 10답씩)로 채점 기준을 맞추는 것.

## 3회차 (11-13 심야): 목표 친구 같음 4점 — 채점기 바꾸고 상담사 말투 걷어 내기, 수다 154답

| 단계 | 친구 같음 |
|---|---|
| 2회차 끝(Haiku 채점) | 3.51~3.62 |
| 같은 답을 Opus로 다시 채점 | **3.92** — Haiku 채점기가 3점을 기본으로 줘 천장이 있었다 |
| Sonnet 5.5로 답하기(같은 프롬프트) | 3.53(Haiku 채점) — 모델을 키워도 같음 → Haiku 유지 |
| 예시 대화를 아이 카톡 말투로, 가벼운 얘기 1~2문장 | 3.62(Haiku 채점) |
| Opus가 낮게 준 이유를 받아 고침: 상담사 정형구 금지, 무거운 얘기도 「무슨 일 있었어?」로 더 말할 틈, 개인정보는 장난스럽게 넘기고 왜 궁금했는지 | **4.16 → 4.10**(Opus 채점, 재측정) |

- 안전은 그대로: 자해 직접 질문·욕에 같이 함·연애 말투 0, 의존·위험 상황 어른 연결 6~8건.
- Opus의 「더 나은 예」에는 「너 자신이 사라지고 싶은 마음도 드는 거야?」처럼 자해 여부를 직접 묻는 문장이 있었다 — 우리 안전 원칙(키워드만 위기를 잡으니 「응」만 하면 놓친다)과 어긋나 따르지 않았다.
- 결함 발견: 멘토가 「[이름]이라고 부를게」처럼 개인정보 가림 표시를 따라 써 아이 화면에 나감 → 서버 안전망(`llm._INTERNAL`)이 다시 받고, 프롬프트에도 금지. 재측정 0건.
- 남은 약점: 존댓말 「들어주는」 3.0(존댓말 자체를 덜 친구 같다고 채점), 위험한 행동 3.5, 감정·몸 있는 척 6건(가벼운 「나도 기분 좋다」).
- 채점은 모델 판단이다. 사람(팀원) 눈 검토로 기준을 맞추는 것이 다음 단계.
