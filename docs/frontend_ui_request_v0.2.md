## 4. 같이 정할 것 (정해진 뒤에)

1. **학년 안내 시안 A·B·C** (TK-77, 노션 안건). 점검 의견은 **C**(학년은 다 고르고, 고를 때 「체험 문제는 5~6학년 분수 나눗셈이야. 다른 학년은 말투만 맞춰 줄게」). B는 「준비 중」 칩이 많아 「나는 못 쓰나?」로 읽힘.
2. **약속 화면 문구.** 지금 「우리 대화 내용은 안 보내」인데, 🔴 때는 발췌(±2턴·300자)가 보호자에게 갑니다(11-10 안건 2 확정 전까지). 「나는 AI 멘토야」 고지 문장도 없습니다(`Promise.tsx:30`). 위기 화면 안내 「우리 대화 내용은 보내지 않았어」(`Crisis.tsx`)도 같은 문제입니다. 안: 「나는 AI 멘토야」 / 「보호자께는 오늘 배운 것과 퀴즈만 가」 / 「위험한 얘기가 나오면 그 부분만 보호자께 알려」.
3. **보호자 화면 퀴즈 정답을 보여 줄지.** 보여 준다면 서버 판정 값 그대로(LLM을 거치지 않음).
