## 3. 후보별 메모 (기존 조사에 없던 것만)

- **Anthropic.** 최신 저가 모델 Haiku 5.5가 Haiku 4.5보다 10배 싸다($0.10/$0.50 vs $1/$5). `inference_geo`는 Claude 4.6 이후만 지원하고 값은 `global`/`us` 두 개, 저장 위치(workspace geo)는 `us`만 [A2]. → "서버는 미국에 있어 국외 이전 동의"(기존 조사 4.9 문구)는 그대로 유효. AUP는 **2026-11-12 발효판**이 현재 게시돼 있고 미성년 조항 문장은 기존 조사와 같다 [A4] — 기존 조사 6절 1번 우려(차기판에서 바뀌는지)는 "문구 동일"로 해소. Fable·Mythos 계열은 「Covered Models」라 30일 보존이 강제되고 ZDR이 안 된다 [A3] — 우리는 쓰지 않는다. 계정 보유자 연령 요건(18세 이상)은 2차 자료로만 확인 — 팀 계정 명의자가 성인인지 확인 필요.
- **OpenAI.** gpt-6-luna가 Haiku 5.5와 같은 단가. 18세 미만 안내 페이지는 여전히 날짜 없이 "13세 미만 개인정보는 ZDR 없이 처리하지 말 것"이고, 보호자 동의는 그 페이지가 아니라 서비스 계약 3.3(c)에 있다 [O2]. 우리 사용자 10~15세 중 10~12세가 걸린다. 시연은 합성 데이터라 당장 위반은 아니나 실서비스 경로가 막힌다. 이용정책 차기판(2026-11-20 시행) 본문은 이번에도 403으로 **미열람**.
- **Google.** 가격은 싸고 무료 구간도 있지만 Developer API(AI Studio)와 Vertex AI(Google Cloud) **둘 다** 18세 미만 대상·접근 가능성 높은 서비스를 금지한다 [G2][G3]. Gemini를 쓰는 길은 약관상 없다. 무료 구간은 EEA·스위스·영국 사용자 대상 앱에서도 금지돼 유료 조건이 적용된다 [G2] — 한국 관련 언급은 없음.
- **Upstage.** 국내 공급자 중 유일하게 공식 요금표와 약관을 열람했다. 약관상 미성년(만 18세 미만)은 **가입자**로 거절될 수 있다는 조항뿐이고, 미성년 최종 사용자에 대한 허용·금지·조건 규정은 찾지 못했다 → 공급자에게 직접 문의해야 판단 가능. 무료 서비스 데이터는 학습에 쓰일 수 있다. 학교·병원·비영리 대상 1년 무료 지원 프로그램이 있으나 학원(영리)은 해당 여부 미확인 [U1].
- **네이버 HyperCLOVA X.** 모델 라인업(HCX-007 추론, HCX-005 멀티모달, HCX-DASH-002 경량)은 확인 [N2]. 요금 금액·미성년 약관·처리 위치는 **모두 미확인**(요금 페이지가 금액 칸을 렌더링하지 않음).
- **카카오 Kanana.** 공개 유료 API 요금표를 찾지 못했다. 오픈웨이트 공개 소식은 2차 보도만 확인.
- **OpenRouter / Groq.** 무료 구간이 있지만 하루 50회(OpenRouter) 같은 한도와 "모델 공급자가 입력을 학습할 수 있음" 조항 때문에 아동 원문(치환본이라도)을 보내기 부적합. Groq 약관은 연령·학습 조항이 비어 있어 판단 근거가 없다.

## 5. 결론 (11-10 회의 안)

1. **1순위: Anthropic Claude API, 모델 `claude-haiku-5-5`.**
   - 이유 ① 미성년자 직접 상호작용을 명시 허용하고 조건이 공개 문서로 있다(11-12 발효판도 동일). ② 기존 결정 「AI 고지 1회」·명세 4.9 문구가 이미 Anthropic 기준으로 쓰여 있어 문서 수정이 없다. ③ 시연 비용 약 700~2,700원. ④ 학습 불사용·30일 보존이 공개 문서에 있다.
   - 품질이 부족하면 같은 어댑터에서 `claude-sonnet-5-5`로 올린다(보수 시나리오에도 5만 원대).
2. **2순위: OpenAI API, 모델 `gpt-6-luna`.** 단가는 같지만 13세 미만 ZDR 요건과 보호자 동의 요건 때문에 실서비스 경로가 더 좁다. Anthropic 계정·결제가 11-10까지 안 되면 이걸로 간다.
3. **제외: Google Gemini(Developer API·Vertex AI 모두), OpenRouter·Groq 무료 구간.** 국내(Upstage·네이버·카카오)는 미성년 최종 사용자 약관 확인 전까지 "후속 검토".
4. **결정 DB 「대회 시연에는 무료·개인 범위 API를 사용하고 상용화 시 유료 공급자로 전환한다」 → 폐기 권고.**
   - 이유: (a) 무료 구간이 실질적으로 쓸 만한 곳(Gemini)은 아동 대상 앱을 약관으로 금지하고 무료 데이터를 학습·사람 검토에 쓴다. (b) 나머지 무료 구간(OpenRouter·Groq)은 한도가 작거나 학습 조항이 불명확하다. (c) 유료여도 시연 전체가 수천 원 수준이라 무료를 쓸 이유가 없다. (d) "시연은 무료, 상용은 유료"로 나누면 심사위원이 "약관상 이 서비스를 실제로 낼 수 있나"를 물을 때 답이 없다.
   - 대체 결정 문장(안): "시연·상용 모두 Anthropic Claude API(Haiku 5.5)를 쓴다. 공급자는 어댑터 뒤에 두고 2순위는 OpenAI. 시연 예산 상한 5만 원."
   - (노션 반영은 사람 승인 뒤. 이 문서 작성 중 노션에는 아무것도 쓰지 않았다.)
