# 디자인 규칙 (v0.5) — GPT·팀원 공용

> 이 문서는 **화면을 고치거나 새로 만들 때 지켜야 할 규칙**이다. 디자인 담당(GPT)이 최종본을 확정하면 이 파일을 갱신한다.
> 코드 위치: `app/src/styles/tokens.css`(값) · `app/src/styles/global.css`(모양) · `app/src/components/`(공통 부품)

## 1. 바꿔도 되는 것 / 바꾸면 안 되는 것
| 바꿔도 됨 | 바꾸면 안 됨 |
|---|---|
| `tokens.css`의 **값**(색·크기·간격·모서리) | 변수 **이름**(`--color-primary` 등) |
| `global.css`의 모양(그림자·여백·애니메이션) | 기존 **클래스 이름**(화면 코드가 사용 중) |
| `.tsx`의 배치(마크업 순서·감싸는 요소) | `src/api/`, `src/state/`, 화면의 `api.` 호출·조건 로직 |
| 새 클래스 추가 | 버튼 문구의 **의미**(문구 다듬기는 가능, 기능 바꾸기 불가) |

`.tsx`를 고쳤다면 `npm run typecheck && npm test`가 통과해야 한다.

## 2. 기준 화면
- 기준 프레임 **360×640**(9:16). 넓은 화면에서는 가운데 폰 프레임으로 보인다.
- 아래쪽 **엄지 영역**에 주요 버튼(`Frame`의 `actions`). 한 화면에 주요(민트) 버튼은 1개.
- 누르는 곳은 최소 **44×44px**. 입력칸 높이 46px 이상.
- 스크롤이 생겨도 주요 버튼은 항상 보이게(`bottom-actions` 고정).

## 3. 색
| 토큰 | 용도 |
|---|---|
| `--color-primary` 민트 | 주요 버튼, 선택됨, 진행 |
| `--color-accent` 머스터드 | 연속 일수, 씨앗 테두리, 주의 안내 |
| `--color-bg` 크림 | 바탕 |
| `--color-danger` | **긴급 알림에만** |
| `--adult-*` | 보호자·학습지도자·학원장·운영자 화면(저채도). `Frame adult` |

- 보라색 쓰지 않음(BRIEF 확정).
- 정답/오답을 빨강으로 표시하지 않는다 → 오답은 머스터드("다시 도전").

## 4. 글자
- 본문 16 / 제목 20 / 큰 제목 24 / 키패드 22 / 보조 13.
- 학생 화면의 보조 글자는 **13px 아래로 줄이지 않는다**(4학년 가독성).
- 숫자는 `.num`(고정폭 숫자).

## 5. 역할별 하단 탭
| 역할 | 탭 |
|---|---|
| 학생 | 오늘 · 기록 · 내 멘토 (상점은 「내 멘토」 안 옷장 → 상점, 오늘 화면 씨앗 칩) |
| 학습지도자 | 범위 · 할 일 · 결과 · 씨앗 · 알림 (강의실은 「할 일」 오른쪽 위) |
| 보호자 | 결과 · 알림 |
| 운영자 | 탭 없음(한 화면) |

- 원장은 별도 역할이 아니다: 학원·학교를 등록해 승인받은 **학습지도자**. 「설정 → 학원 관리」로 들어간다.
- 탭 첫 화면: 왼쪽 위 **설정(톱니)**, 오른쪽 위 **알림함(종, 안 읽은 수 = 머스터드 숫자)**. 뒤로가기 없음.
- 로그인·가입·풀이·수다 화면에는 탭을 숨긴다.

## 5-1. 계정 화면 구성 (일반 앱 관례)
| 화면 | 구성 |
|---|---|
| 로그인 `/login` | 캐릭터·앱 이름 → 아이디 → 비밀번호(보기 토글) → 자동 로그인 체크 → 로그인 → `아이디 찾기 \| 비밀번호 찾기 \| 회원가입` → (맨 아래) 체험 계정 |
| 회원가입 `/signup` | 3단계 + 진행 막대: ① 누구인가요(학생·보호자·학습지도자) ② 약관(전체 동의, [필수]/[선택], 보기) ③ 정보(아이디 중복 확인, 비밀번호·확인, 이름, 학년 또는 이메일) → 가입 완료 `/welcome` |
| 찾기 `/find` | 탭: 아이디 찾기(이메일) / 비밀번호 찾기(아이디+이메일). 학생은 보호자가 재설정 안내 |
| 설정 `/settings` | 프로필 카드 → 역할별 묶음(연결·학원 / 자녀·학원 / 소속·수업) → 계정(프로필·비밀번호·알림) → 고객 지원(공지·FAQ·문의) → 약관·정보(이용약관·개인정보·버전) → 로그아웃 → 회원 탈퇴(작게) |
| 알림함 `/notifications` | 최신순, 안 읽은 것은 머스터드 점, 누르면 관련 화면 |

- 입력 칸 아래 도움말: `.hint`(회색) / `.hint--ok`(민트, 통과) / `.hint--bad`(머스터드, 다시). 빨강 쓰지 않음.
- 설정 목록: `.set-group` `.set-item`, 켜고 끄기는 `.switch`.

## 7. 캐릭터 그림 규칙 (B 플랫, 말띠·원숭이띠)
경로: `app/public/mascot/{animal}/` · `animal` = `horse` | `monkey`

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `{mood}.png` | 512×512 투명, 전신 | 96px 초과 |
| `{mood}-face.png` | 상반신 | 57~96px |
| `{mood}-avatar.png` | 머리 | 56px 이하 |
| `outfit-{id}.png` | 전신, **wave 자세** | 옷 입은 캐릭터(내 멘토·상점) |
| `outfit-{id}-face.png` | 상반신, wave | 오늘 화면 머리 그림 |
| `emote-{id}.png` | 256×256 투명 | 상점·수다 이모티콘 |

- mood: `wave` `think` `cheer` `promise` `calm` `read`
- 옷 id: `glasses`(공부 안경) `raincoat`(노란 우비) `scarf`(겨울 목도리) `cape`(별 망토)
- 이모티콘 id: `thumbs`(엄지 척) `thanks`(고마워) `sleepy`(졸려) `best`(최고야)
- 파일이 없으면 앱은 기본 그림/자리표시를 보여 준다(오류 없음). **이름만 맞추면 코드 수정 없이 들어간다.**
- 한 장 150KB 이하 권장. 같은 동물·같은 구도(발끝·머리 위 여백 동일).

## 8. 씨앗(재화) 표현 — 아이 대상 안전 규칙
- 이름은 **씨앗**. 돈·동전·보석 모양을 쓰지 않는다(새싹 아이콘).
- **넣지 않는 것**: 랜덤 뽑기·확률 상품, 현금 충전, 친구와 씨앗 비교(랭킹), "지금 안 사면 사라져요" 같은 재촉.
- 얻는 방법은 화면에 항상 적는다: 학습 완료 +3 · 보호자 도장 +2 · 선생님 칭찬.
- 모자라면 버튼에 "N개 더"로 남은 양을 보여 준다(빨강·경고 금지).
- 보호자 도장은 "이야기 내용 평가"가 아니라 "이야기를 나눈 것"에 찍는다는 문구를 지운다면 안 된다.

## 9. 말투
- 학생 화면 문구는 멘토 말투 설정(반말/존댓말)을 따른다: 코드에서 `say('반말', '존댓말')`.
- 어른 화면은 존댓말 고정.
- 역할 이름은 **학습지도자**(강사 X). 아이에게 보이는 문구에서는 "선생님"을 써도 된다.

## 10. 움직임·접근성
- 애니메이션은 0.3초 이하, `prefers-reduced-motion`이면 끈다.
- 색만으로 상태를 구분하지 않는다(글자·아이콘 함께).
- 포커스 테두리(`:focus-visible`) 지우지 않기.
