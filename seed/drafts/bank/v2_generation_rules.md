# 문제 생성 프롬프트용 공통 규칙 (v2)

1~10은 `blueprint_review.md` 5절을 그대로 옮겼다. 11~20은 v2 설계도를 고치며 더한 규칙이다.

## 검토에서 옮긴 규칙

1. 답은 하나뿐이어야 한다. 정답이 둘 이상 나올 수 있으면 조건을 문제에 적거나 객관식으로 바꾼다. 「어림」「대략」「알맞은 말 쓰기」처럼 열린 질문은 만들지 않는다.
2. 수학 답은 양의 정수·분수·유한소수·대분수(「1 2/3」) 하나다. 문제 끝에 「숫자만 써 주세요」를 붙이고, 음수·쉼표·단위·식·좌표·구간이 답이 되는 문제는 만들지 않는다.
3. 그림·그래프·밑줄·굵은 글씨 없이 글만으로 풀려야 한다. 도형은 꼭짓점 이름과 조건으로, 그래프는 표나 수치로, 밑줄은 ①②나 (가)(나) 기호로 대신한다.
4. 설계도의 `out_of_scope`에 있는 개념은 풀이 과정에서도 쓰지 않는다. 풀이가 다음 학년 개념을 요구하면 버린다(중2 피타고라스 답에 √, 초4 답에 약분·통분 등).
5. 오답 보기와 힌트는 설계도의 `misconceptions`에서 만든다. 문항마다 어떤 오개념을 겨냥하는지 한 줄로 적는다.
6. 지문·시·대화는 모두 새로 쓴다. 교과서·기출·실제 작품·실존 인물·기관·상표를 쓰지 않는다. 지문 길이는 설계도 상한(초4 4문장, 중2 60단어, 고1 80단어)을 넘기지 않는다.
7. 단답(text)은 한 낱말이다. 허용 표기(대소문자, 띄어쓰기, 「직유/직유법」, can't/cannot)를 `accepted`에 모두 적는다. 한 유형의 단답이 모두 같은 꼴(-ing만, 「사실」만)이 되지 않게 섞는다.
8. 맞춤법·발음·사전 순서·영어 철자 정답은 표준국어대사전과 기본 어휘 목록으로 대조했다는 표시를 문항에 남긴다. 대조하지 못한 문항은 `needs_review`로 표시한다.
9. 초4 문제 글은 쉬운 우리말로 쓴다(교과 한자 용어 금지, 영어 문제 지시문도 한국어). 초4 영어는 뜻과 상황을 묻고 어법 옳고 그름은 묻지 않는다.
10. 한 단원 20문제 안에서 같은 수·같은 낱말·같은 지문 소재를 되풀이하지 않고, 난이도는 설계도의 유형별 개수를 그대로 지킨다.

## v2에서 더한 규칙

11. **수학은 단원의 `answer_rules`를 문항마다 그대로 지킨다.** 채점기(`backend/app/judge.py`)가 읽는 형식은 자연수·분수(3/4)·유한소수(0.25)·대분수(「1 2/3」, 사이 한 칸)·「a÷b」·「b분의 a」뿐이다. 약분 안 한 분수도 값이 같으면 정답이다. 「1과 2/3」, 「60°」, 「1,234」, 「12개」, 「-3」은 판정하지 못한다(정답이어도 코칭으로 넘어감).
12. 문제 끝 안내는 단원 `answer_rules`가 정한 문구를 쓴다. 기본은 「(숫자만 써 주세요)」, 단위를 붙이기 쉬운 단원은 「(°나 도 없이 숫자만 써 주세요)」「(쉼표 없이 숫자만 써 주세요)」처럼 무엇을 빼야 하는지 적는다.
13. 분수가 답인 문제는 문제 글에 입력 예(「3/4」 또는 「4분의 3」, 대분수는 「1 2/3」)를 한 번 보여 준다.
14. 수학에서 보기 고르기가 꼭 필요하면 보기를 ①~④로 주고 「번호를 숫자로 써 주세요(예: 3)」로 안내한다(채점기가 ③을 3으로 읽는다). 보기 내용이 수인 문항에는 쓰지 않는다. 지금은 `g10-math-sets-propositions`의 증명 빈칸 2문제에만 쓴다.
15. 수학 문항마다 `problem_types[].covers`의 성취기준 코드 중 하나를 문항의 `standard.code`로 적는다. 한 유형이 코드 두 개를 덮으면 문항을 두 코드에 나눠 배정한다.
16. 순환소수는 「0.1666…(6이 되풀이)」, 행렬은 「A = [[1, 2], [3, 4]] (첫째 묶음이 1행)」, 근호는 「√(x − 2)」처럼 폰에서 깨지지 않는 글자로 쓴다. 점 찍은 문자(0.16̇)·위첨자 조합 문자는 쓰지 않는다.
17. 상수·근·해가 둘 이상 나올 수 있는 고1 문제는 「양수인」「x > y인」「정수 중 가장 작은」처럼 조건을 문제에 적어 답을 하나로 만든다. '정수 해의 개수'를 물을 때는 음수 정수를 세는지 알 수 있게 '정수'와 '자연수'를 분명히 쓴다.
18. 영어 단답 중 정답이 여럿인 연결어·관계사는 문제 글에 후보 단어를 주고 그중 하나를 치게 하거나(`g10-eng-logical-flow`), 정답 표기를 모두 `accepted`에 넣는다.
19. `grade_band`가 있는 단원은 학교마다 배우는 학년이 다르다. 문제 글에 「중2에서 배운」처럼 학년을 쓰지 않는다.
20. notes에 「1차 확인 대기」가 있는 단원(중2 무게중심·넓이비, 고1 범위, 중2 국어 코드 등)은 확인 결과가 나오면 설계도를 먼저 고친 뒤 생성한다. 확인 전 생성분에는 `needs_review`를 붙인다.
