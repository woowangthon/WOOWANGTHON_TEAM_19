# 문제 은행 확장 한 장 요약 (발표용, 11-13)

**한 줄:** 시연은 초6 분수 20문제다. 그다음 단계로 **초4·중2·고1 × 수학·국어·영어 49단원을 설계했고, 그중 3단원 60문제를 시범으로 만들어 두 번 검토하고 실제 화면에서 끝까지 풀어 봤다.** 서버에서 학년별로 내는 일은 아직 남았다.

## 1. 설계: 49단원
| | 초4 | 중2 | 고1 |
|---|---|---|---|
| 수학 | 5 | 5 | 9 (1년 전체) |
| 국어 | 5 | 5 | 5 |
| 영어 | 5 | 5 | 5 |

- 단원마다 다음을 정했다:
  - 성취기준 코드(2022 개정). 51개는 NCIC 원문과 대조했다.
  - 핵심 개념과 자주 틀리는 오개념
  - 문제 유형과 개수, 난이도 배분
  - 범위 밖 개념
- 교과서 단원명과 기출 문제는 쓰지 않았다. 지문과 예문은 새로 썼다.

## 2. 시범: 3단원 60문제
- 초4 수학 「큰 수」, 중2 국어 「품사」, 고1 영어 「관계사」, 단원마다 20문제다.
- 답 형식은 세 가지다:
  - 숫자: 숫자판으로 입력
  - 보기 고르기: ①~④ 버튼
  - 낱말 쓰기: 영어/한글 안내가 나오는 입력칸
- **정답은 코드가 정한다.** 수학은 계산식을 다시 계산해 맞춰 보고, 보기와 낱말 문제는 허용 답 목록으로 판정한다.

## 3. 검수 결과
| 단계 | 결과 |
|---|---|
| 자동 검사기 | 60문제 FAIL 0 |
| 1차 검토(직접 풀이) | 정답 오류 0. 고칠 것 38(대부분 「힌트 2가 답을 다 알려 줌」) → 모두 고침 |
| 2차 독립 검토(단원 적합성) | 빠진 개념을 보충: 수학 10배·100배, 영어 in which, 국어 조사 |
| 사전 대조 | 국어 2문제를 표준국어대사전·우리말샘과 대조해 확인 |
| 실제 화면(320px 폰) | 60/60을 끝까지 풂. 입력 화면 종류, 오답→정답, 영어 문제에 한글 입력 막기 |
| 힌트 단계(API) | 60/60. 힌트 1 → 2 → 풀이 순서. 멘토 답에서 정답 누설 0(대본 모드) |

## 4. 대량 생성 규칙(시범에서 배운 것)
- **힌트 누설 기준:** 힌트 2를 읽은 뒤에도 아이가 스스로 할 한 걸음이 남아야 한다. 누설 꼴 6가지는 금지한다.
- 정답이 하나뿐인지 확인한다(영어 관계사 후보를 모두 넣어 봄, 국어 품사 통용어 목록).
- 「어려움」은 외우면 되는 문제가 아니라 풀이 걸음 수로 정한다.
- 생성 → 자동 검사 → 모델 검토 → 사람 검수 순서로 진행한다. 남은 약 900문제는 제출 뒤에 만든다.

## 5. 남은 일(정직하게)
- 서버가 아직 학년으로 문제를 고르지 않는다. 가입 학년이 「초5-6」으로 고정돼 있고, 단원 이름표도 고쳐야 한다. 예상 작업량은 하루다(`server_todo.md`).
- 실제 AI 모델로 국어·영어 정답 누설을 아직 시험하지 않았다.
- 모든 문제는 AI가 만들었고, 교사 검수와 유사성 대조는 아직 하지 않았다.
