# 학년별 문제를 서버에서 쓰려면 남은 일 (11-13, TK-56-deploy@722e9ae 기준)

**읽는 사람:** 프리즈 뒤 학년별 문제 은행을 붙일 코드 담당, 발표·README의 「다음 단계」를 쓰는 사람.
**한 줄:** 문제 데이터와 답 입력(숫자·보기·낱말)은 준비됐다. 서버가 **학년으로 문제를 고르지 않는 것**이 남은 핵심이다. 코드는 고치지 않았다.

## 이미 된 것 (근거)

- 시범 60문제: 초4 수학 「큰 수」, 중2 국어 「품사」, 고1 영어 「관계사」. 검사기 FAIL 0이고, 두 번 검토해 고쳤다(`bank/pilot_review.md`, `bank/pilot_fix_log.md`).
- 답 입력 종류: 숫자 한 칸(12자리), 보기 버튼, 낱말(영어/한글 안내, 「부사요」 허용). 브랜치 `wip-answer-kinds`(커밋 전)에 있고, chingu1-37이 합친다. 설명은 `handoff/1113_to_code_answer_kinds.md`.
- 실측: 그 브랜치에 고친 60문제를 넣고 320px 화면에서 끝까지 풀었다. 60/60 정답·오답 판정이 정상이고, 화면 넘침은 0이다.
